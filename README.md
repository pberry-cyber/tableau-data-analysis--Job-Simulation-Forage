# tableau-data-analysis-Job-Simulation-Forage

## Executive Summary
This project showcases data visualization and analytical solutions to Deloitte Data Analytics via Forage. The analysis focuses on processing complex telemetry data from manufacturing plants operated by the client **Daikibo** to identify operational bottlenecks, machine breakdown frequencies, and equipment downtime patterns across global facilities.

## Key Problem & Business Context
* **Client:** Daikibo Industrial Manufacturing
* **Objective:** Analyze machine failure logs and telemetry data across four global manufacturing plants (Tokyo, Osaka, Berlin, and Shenzhen) to reduce operational downtime.
* **Core Business Question:** Which factory experiences the highest downtime, and which specific machine types account for the highest frequency of failures?

---

## Strategic Insights & Findings
* **Primary Bottleneck:** Identified the specific factory location causing the majority of manufacturing delays and equipment stoppage hours.
* **Equipment Failures:** Isolated high-risk machine types (device types) that require targeted preventive maintenance schedules to eliminate recurring downtime.
* **Operational Impact:** Converted status telemetry logs into actionable operational metrics to allow plant managers to prioritize field engineering interventions.

---

## Tools & Technical Skills Applied
* **Data Visualization:** Tableau Desktop / Tableau Public
* **Data Modeling:** Calculated fields (e.g., status flags and telemetry downtime metrics), data aggregation, custom grouping
* **Analytics Framework:** Root Cause Analysis, Operational Performance Management, Executive Reporting
